## Usage

Fluid typography scales up or down based on the size of the viewing device or browser
window within a predefined min-max font size.

### Do
- Use fluid font styles as default
- Center-align section headings
- Ensure headlines align to the same vertical grid line when left-aligned
- Use only predefined font styles for consistency
- Use display styles for hero intro, stats, or emotional moments
- Use headline-xx-large for section appointments
- Use text-styles for running text
- Text-small is the default; larger styles work for introductions and short descriptions
- Pair headline styles with text styles one or two steps below
- Use text-xx-small only for disclaimers

### Don't
- Don't use static font styles
- Don't use thin or italic styles of Porsche Next

## Styles

Display: large / medium / small. Heading: xx-large through small.
Text: x-large through xx-small. Delivered as JS style objects and SCSS mixins.
