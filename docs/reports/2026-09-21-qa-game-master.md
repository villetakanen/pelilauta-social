## Impression

Pelilauta provides a remarkably well-tailored campaign hosting environment. The combination of markdown-based wiki pages, session logs, automated table of contents, GM tools (clocks, secrets), member permissions, and especially the full Markdown/Zip export gave me confidence that prep time invested here won't be trapped in a proprietary silo. A few UI rough edges like untranslated back buttons and a two-step page creation workflow are minor quirks in an otherwise great tool.
