# Provenance

The images in this directory are OpenAI-generated test material. Nobody drew them
and no photograph carries them; a model generated each one for use as acceptance-test
seed content only.

Do not use an image from this directory outside the acceptance-testing seed, and do
not treat one as licensed content: it carries no attribution, no ownership claim, and
no permission for reuse beyond driving these tests.

| :--- | :--- |
| `bellweather-knives-hero.png` | `sites/bellweather-knives`, `posterURL` and `backgroundURL`. The seeder uploads it; no spec does. |
| `gloamroad-company-upload-fixture.png` | Not seeded. An asset-upload spec drives the upload through the running application. |
