Our spatial system is built on an 8px (`0.5rem`) base grid unit. It governs recurring
layout intervals, component padding, corner radii, and elevation shadow geometry.
Icon dimensions follow an independent scale documented in [Iconography](/principles/iconography).

## Core measurements

We define three primary spatial intervals across the system:
- `--cn-grid` (`0.5rem` / 8px): The base unit every other measurement multiplies.
- `--cn-gap` (`1rem` / 16px): The standard interval for layout gutters and surface insets.
- `--cn-line` (`1.5rem` / 24px): The baseline unit for text leading, control row heights, and section rhythm.

## Component spatial relationships

| Token | Use | Not |
| :--- | :--- | :--- |
| `--cn-grid` | The base every other measurement multiplies; a control's geometry, and the space between the symbols inside it | An interval between two pieces of content |
| `--cn-gap` | Surface inset; the interval between siblings — the avatar and its identity text, one action and the next | |
| `--cn-line` | The interval between stacked blocks — the identity and the message body | |

Common uses, not a mapping from content relationship to measurement.

## Grouping and proximity

The smaller of two intervals in one composition reads as tighter. Below, the label stays with
its heading and the action separates; one interval throughout makes all three an equivalent
group. Repeated rows use the same interval because they are equivalent relationships.

## Composition boundaries

Components define their internal padding and dimensions. Parent flex and grid layouts
control spacing between sibling components using `gap`, enabling fluid reordering and
wrapping.

The [Surface](/base/surface) container applies `--cn-gap` padding on all sides, ensuring
nested panels align without manual inset adjustments. Page-level column measures and
breakouts are managed by [Content containers](/base/content-containers).

## Vertical rhythm

`--cn-line` establishes the 24px baseline rhythm across typography and interactive controls.
A control sized to one line unit aligns flush with adjacent single-line body text. Separating
stacked blocks by `--cn-line` maintains that rhythm.

For typographic scale details, see [Typography principles](/principles/typography).

## User font scaling

### Relative font units

All spatial intervals, corner radii, and breakpoint thresholds are declared in `rem`.
Our stylesheets do not override `font-size` on `html` or `:root`, ensuring all layout
dimensions and spacing scale proportionally with the user's browser font preferences.

## Radius and shadow geometry

Corner radii scale in grid multiples: half-grid (`4px`), 1-grid (`8px`), 2-grid (`16px`),
and 4-grid (`32px`). Rounded containers maintain at least one grid unit of interior padding
to prevent content from clipping curved corners.

<SpatialRadii source={unitsSource} utilitySource={spatialSource} />

Elevation shadow offsets and blur radii are derived directly from `--cn-grid`. Elevation
tiers, theme contrast mappings, and nested surface behaviours are defined in
[Colour & Surface](/principles/color-system).
