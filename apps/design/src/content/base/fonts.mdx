We provide two typefaces. **Lato** sets UI and editorial content. **Roboto Mono** sets
machine text: code, the label step, and text the reader types in.

## Available faces

Our stylesheets declare only the weights and styles listed below. Declaring an unlisted
combination triggers browser font synthesis (faux bold or oblique).

<FaceTable source={fontsSource} family="Lato" />

<FaceTable source={fontsSource} family="Roboto Mono" />

Faces are their publishers' files, unmodified. Lato is published whole, one file per
weight. Roboto Mono is published split by alphabet, so it takes the publisher's `latin`
and `latin-ext` files. Every face declares `font-display: swap`. No face is preloaded.

For step mappings and typographic hierarchy, see [Typography](/principles/typography).

## Element assignments

| Element | Typeface |
| :--- | :--- |
| Root document and inherited text | Lato |
| `button` | Lato |
| `input`, `select`, `textarea` | Roboto Mono |
| `code`, `kbd`, `samp`, `pre` | Roboto Mono |
| `.text-label` | Roboto Mono |
