## Faces

These weights and styles have a real face. Ask for one that is not here and the
browser synthesises it: it renders, and it is not the typeface.

<FaceTable source={fontsSource} family="Roboto Mono" />

Each face ships as two files, `latin` and `latin-ext`, so a page downloads only the
coverage it uses. Characters in neither range fall back to the reader's own fonts.

Every face is `font-display: swap`. None is preloaded.

Which weight belongs to which step is [Typography](/principles/typography)'s.

## Which element gets which

| Element | Typeface |
| :--- | :--- |
| The document, and everything inheriting from it | Lato |
| `button` | Lato |
| `input`, `select`, `textarea` | Roboto Mono |
| `code`, `kbd`, `samp`, `pre` | Roboto Mono |

Identifiers and slugs are technical too, but nothing selects them yet. They arrive
with the typography semantics.

## Changing the face set

The `.woff2` files are committed in `packages/design-system/fonts/`. After adding or
dropping a face, regenerate them:

```
pnpm --filter @pelilauta/design-system cut:fonts
```
