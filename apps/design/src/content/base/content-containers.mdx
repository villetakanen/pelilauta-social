Content containers establish reading measure, fluid gutter margins, and vertical
separation between stacked layout blocks.

## Application opt-in

Adding `cn-app-main` to `<main>` lays its direct children out on the page grid, without
intermediate wrappers. A `<section>` is one container in the column. An `<article>` spans
the page and passes the grid to its blocks through subgrid: each block is a container in
the column.

```html
<main class="cn-app-main">
  <section>A container in the column.</section>
  <article><p>A block in the column.</p></article>
</main>
```

Every rule is scoped below the opt-in class, so a page without it is untouched.

## Container query context

A container establishes the `cn-content` container query context, exposing the column's
inline size to descendant components: the section in one case, each block in an article.

```css
@container cn-content (max-width: 30rem) { … }
```

The query evaluates the content column directly rather than the full viewport width.

## Fluid column sizing

Containers adjust between the reading measure and viewport gutters using a single
continuous grid track:

```css
grid-template-columns: 1fr min(var(--cn-measure), 100% - 2 * var(--cn-gap)) 1fr;
```

On wide viewports, content centers at `--cn-measure` with equal margins. On viewports
narrower than the measure plus gutters, the container maintains a `--cn-gap` gutter on
each side without breakpoint jumps.

## Measure calculation

`--cn-measure` evaluates to `calc(var(--cn-grid) * 83)` (41.5rem).

This value corresponds to 67 characters of Lato at the 17px body size (0.58em
advance width, yielding 660.6px or 82.58 grid units, rounded up to 83). Defining
the measure in grid units rather than `ch` prevents layout shift during font
loading and prevents size inheritance anomalies in headings. Because the value is
expressed in `rem`, the column scales proportionally with user browser font settings.

For font scaling principles, see [Spatial System](/principles/spatial-system).

## Vertical rhythm

Stacked containers and top-level block elements inside a container are separated by
`--cn-line` (24px). Vertical rhythm tokens are defined in [Units and grid](/tokens/units).

## Full-bleed containers

To span the full viewport width, apply `cn-grid-full` to a top-level container element.

```html
<main class="cn-app-main">
  <section>A container in the column.</section>
  <section class="cn-grid-full">Full-width section spanning the viewport.</section>
</main>
```

In a section, breakout is a property of the container: a child cannot exceed a container
that is exactly the column's width. In an article, a block marked `cn-breakout` takes the
width its content wants, centred, up to the page, and is not a container.
