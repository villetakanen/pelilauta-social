## The host

A container asks the nearest ancestor that establishes an inline-size containment
context, and takes the content-box width that ancestor offers. The application frame
is the usual one; any element declaring `container-type: inline-size` serves.

| Token | Applies to |
| :--- | :--- |
| `--cn-line` | The separation a container states after itself, and between the top-level blocks inside one. |

See [Units and grid](/tokens/units).

```html
<div style="container-type: inline-size">
  <section>As wide as the host offered.</section>
  <article class="content-prose"><p>Centred at the measure.</p></article>
</div>
```

## The measure

A prose flow caps at `--cn-measure`, and a golden primary takes the same width. It
holds 67 characters of Lato at the reading size, and scales with the reader's browser
font settings. The value is published in [Units and grid](/tokens/units), and
[Spatial System](/principles/spatial-system) explains where it recurs.

The flow centres at the measure where the host offers more, and fills the host where it
offers less.

## Container query context

Each item in the flow is an inline-size container, so a component asks about the column
it sits in rather than the window. The container is unnamed: an unnamed query resolves
against the nearest one, which is the area holding the component. Where a card sits
between the two, the card answers, and the card is what constrains the component.

```css
@container (max-width: 30rem) { … }
```

## Breaking out of the measure

Inside a prose container, a child marked `breakout` leaves the measure and takes the
width the container itself was offered. Use it for a table, a diagram, or a specimen
that a reading column would crop.

<div class="breakout surface">
  This block is a breakout. It is as wide as this page was offered, and it reports that
  width to the components inside it.
</div>

```html
<div class="breakout surface">
  This block is a breakout. It is as wide as this page was offered, and it reports that
  width to the components inside it.
</div>
```

## Golden

`content-golden` puts a readable primary and one small secondary in one row, in source
order.

| Region | Grid units |
| :--- | :--- |
| Primary | 83, the measure |
| Secondary | 32 |

The row appears where the host offers 117 grid units — the two regions and the
`--cn-gap` between them — or more. Below that the regions stack and fill the host.
The row is centred in whatever the host offers beyond it, so the primary does not line
up with a prose flow above it.

The demonstration below sits in a breakout, which is its host. Narrow the window to
stack it.

<div class="breakout">
  <div class="content-golden">
    <div class="surface elevation-2">Primary. As wide as a prose flow.</div>
    <div class="surface elevation-2">Secondary.</div>
  </div>
</div>

```html
<div class="content-golden">
  <div class="surface elevation-2">Primary. As wide as a prose flow.</div>
  <div class="surface elevation-2">Secondary.</div>
</div>
```

A golden container has exactly two regions.

## Triad

`content-triad` lays its three regions out in one row: a medium primary and two small
secondaries, in source order.

| Region | Grid units |
| :--- | :--- |
| Primary | 51 |
| Secondary | 32 |
| Secondary | 32 |

The row appears where the host offers 119 grid units — the three regions and the two
`--cn-gap` between them — or more. Below that the regions stack and fill the host.
The row is centred in whatever the host offers beyond it.

The demonstration below sits in a breakout, as the golden one does.

<div class="breakout">
  <div class="content-triad">
    <div class="surface elevation-2">Primary. The medium region.</div>
    <div class="surface elevation-2">Secondary.</div>
    <div class="surface elevation-2">Secondary.</div>
  </div>
</div>

```html
<div class="content-triad">
  <div class="surface elevation-2">Primary. The medium region.</div>
  <div class="surface elevation-2">Secondary.</div>
  <div class="surface elevation-2">Secondary.</div>
</div>
```

A triad has exactly three regions.

## What counts as a region

A `script`, `style` or `template` child of a golden or triad container does not take a
track. An `astro-island` counts as the single region it renders — including while a
deferred island is still showing its fallback, which is why a deferred region renders
one element in every one of its states.

A prose flow child follows the same rule: an island is the one element it renders, so a
hydrated component may sit directly in a prose container and still take the measure, and
carry `breakout` and receive breakout layout.

Each region reports its own track to the components inside it, and under `surface-area`
as well where the region is a surface.

A region is as tall as its own content, and the row is as tall as its tallest region.
A short region that paints — a surface, a bordered aside — therefore ends where its
content ends. A region that wants the height of the one beside it asks for that
itself, with `align-self: stretch`.
