A content container lays its children out in rows of one, two or three columns, in
source order. Put one mode class on the element holding the children.

## Modes

| Mode | Class | Columns | Column measures, in grid units |
| :--- | :--- | :--- | :--- |
| Prose | `content-prose` | 1 | 83, the measure |
| Golden | `content-golden` | 2 | 83, 32 |
| Triad | `content-triad` | 3 | 51, 32, 32 |

A container carries exactly one mode class. Golden's row needs 117 grid units and
Triad's needs 119, counting the `--cn-gap` between adjacent columns. Below that width,
and in Prose at any width, the mode is rows of one column filling the width offered.

The measure is published as `--cn-measure` in [Units and grid](/tokens/units), and
[Spatial System](/principles/spatial-system) explains where it recurs. Prose centres its
column at the measure when the container is offered more, and fills the width offered
when it is offered less.

## The box a container sits in

A container resolves its columns against the nearest ancestor that establishes an
inline-size containment context, and takes the content-box width that ancestor offers. The application frame is
the usual one; any element declaring `container-type: inline-size` serves, down to a box
the size of a card. Containers nest.

A container adds no inset. State any page-edge inset on the box the container sits in.

```html
<div style="container-type: inline-size">
  <section>As wide as the box offered.</section>
  <article class="content-prose"><p>Centred at the measure.</p></article>
</div>
```

## Rows

Children fill the columns of a row in source order and continue on the next row. A last
row holding fewer children than the mode has columns leaves the remaining columns empty.
No child count is invalid.

| Token | Applies to |
| :--- | :--- |
| `--cn-line` | The separation between the rows of a container, and after the container itself. |
| `--cn-gap` | The inline gap between the columns of one row. |

The demonstration below sits in a breakout, and resolves its columns against it. Narrow
the window to bring it down to one column.

<div class="breakout">
  <div class="content-golden">
    <div class="surface elevation-2">First child. As wide as a prose column.</div>
    <div class="surface elevation-2">Second child.</div>
    <div class="surface elevation-2">Third child, on the next row.</div>
    <div class="surface elevation-2">Fourth child.</div>
  </div>
</div>

```html
<div class="content-golden">
  <div class="surface elevation-2">First child. As wide as a prose column.</div>
  <div class="surface elevation-2">Second child.</div>
  <div class="surface elevation-2">Third child, on the next row.</div>
  <div class="surface elevation-2">Fourth child.</div>
</div>
```

A triad lays the same children out three to a row.

<div class="breakout">
  <div class="content-triad">
    <div class="surface elevation-2">First child.</div>
    <div class="surface elevation-2">Second child.</div>
    <div class="surface elevation-2">Third child.</div>
    <div class="surface elevation-2">Fourth child, alone on the last row.</div>
  </div>
</div>

```html
<div class="content-triad">
  <div class="surface elevation-2">First child.</div>
  <div class="surface elevation-2">Second child.</div>
  <div class="surface elevation-2">Third child.</div>
  <div class="surface elevation-2">Fourth child, alone on the last row.</div>
</div>
```

## Breaking out

A child marked `breakout` spans every column of its row, in every mode, and begins a row
of its own. In Prose that span is the whole width offered to the container. Use it for a
table, a diagram, or a specimen that a reading column would crop.

<div class="breakout surface">
  This block is a breakout of the prose container holding this page. It is as wide as
  the page was offered, and it reports that width to the components inside it.
</div>

```html
<div class="breakout surface">
  A breakout of the prose container holding this page.
</div>
```

In Golden and in Triad the row before a breakout ends wherever it had reached.

<div class="breakout">
  <div class="content-golden">
    <div class="surface elevation-2">First child.</div>
    <div class="breakout surface elevation-2">A breakout, on a row of its own.</div>
    <div class="surface elevation-2">The row after it starts at the first column.</div>
  </div>
</div>

```html
<div class="content-golden">
  <div class="surface elevation-2">First child.</div>
  <div class="breakout surface elevation-2">A breakout, on a row of its own.</div>
  <div class="surface elevation-2">The row after it starts at the first column.</div>
</div>
```

Containers stack inside a breakout as they stack anywhere, one `--cn-line` apart.

<div class="breakout">
  <div class="content-triad">
    <div class="surface elevation-2">A triad.</div>
    <div class="surface elevation-2">Second child.</div>
    <div class="surface elevation-2">Third child.</div>
  </div>
  <div class="content-golden">
    <div class="surface elevation-2">A golden below it.</div>
    <div class="surface elevation-2">Second child.</div>
  </div>
</div>

## A card-sized box

The mode class states nothing about the width available, so the same three containers
compose down to a box the size of a card. Each is rows of one column there.

<div style="container-type: inline-size; inline-size: 22rem;">
  <div class="content-prose">
    <p>Prose fills the box, and adds no inset.</p>
  </div>
  <div class="content-golden">
    <div class="surface elevation-2">Golden, first child.</div>
    <div class="surface elevation-2">Second child.</div>
  </div>
  <div class="content-triad">
    <div class="surface elevation-2">Triad, first child.</div>
    <div class="surface elevation-2">Second child.</div>
    <div class="surface elevation-2">Third child.</div>
  </div>
</div>

```html
<div style="container-type: inline-size; inline-size: 22rem;">
  <div class="content-triad">…</div>
</div>
```

## Container query context

Each child of a container is an inline-size container reporting the width it occupies,
which for a breakout is the whole width offered. A component inside queries the
column it sits in rather than the window.

The boundary is unnamed, so an unnamed query resolves against the nearest one. Where a
card sits between the component and the column, the query resolves against the card,
which is the box constraining the component.

```css
@container (max-width: 30rem) { … }
```

## What takes a column

A `script`, `style` or `template` child takes no column. An `astro-island` takes none
either: each element it renders is a child in the island's place, so a hydrated
component sits directly in a container, takes a column, and carries `breakout` — in
every state a deferred island moves through.

## Height

A child is as tall as its own content, and a row is as tall as its tallest child. A
child that must match the height of the one beside it states that itself, with
`align-self: stretch`.

A child box stays within its column, including where a descendant has an oversized
intrinsic width or unbreakable content. What a child holds, and how the child spaces it,
belongs to the child.
