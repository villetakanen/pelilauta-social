Pelilauta uses a modern reset, based on the work of
[Andy Bell](https://piccalil.li/blog/a-more-modern-css-reset/) and
[Tailwind Preflight](https://tailwindcss.com/docs/preflight). Any deviations from their
baseline are documented here.

## Extensions

Astro wraps a hydrated component in an `astro-island` element. It is made transparent,
so an island lays out as though its markup were written in place.

```css
astro-island { display: contents; }
```

The document declares both colour schemes, dark first. An application's
`<meta name="color-scheme">` must state the same order, because the property overrides
the tag.

```css
:root { color-scheme: dark light; }
```

`body` takes the semantic background and text roles rather than literal colours.

## List markers

Removed only on `[role="list"]`, following Bell; Tailwind removes them from every list.
Safari drops a list's semantics from VoiceOver when `list-style` is removed, so a
navigation or menu asks for both. Margin and padding are zeroed on every list either
way.

```css
ol[role="list"], ul[role="list"], menu[role="list"] { list-style: none; }
```

## Owned elsewhere

| Concern | Owner |
| :--- | :--- |
| Prose margins, type sizes, leading, heading wrap | the type ramp |
| Constraining image width | the container holding the image |
| Scrollbar appearance | themed surfaces, unassigned |
| How a control looks once normalised | its component |

Bell and Tailwind both zero prose margins in the reset. Here that waits for the type
ramp, which states the replacement rhythm in the same change.
