Our preflight reset establishes baseline browser styles across all applications.
It adapts patterns from Andy Bell's modern reset and Tailwind Preflight to our
layout and accessibility requirements.

## List markers

List markers are removed only from elements declared with `[role="list"]`. Removing
`list-style` without an explicit role causes Safari VoiceOver to drop list semantics.
All lists reset to zero margin and padding.

```css
ol[role="list"], ul[role="list"], menu[role="list"] { list-style: none; }
```

## Margins and padding

All elements, pseudo-elements, and backdrops reset to zero margin and padding. We
declare no default paragraph or heading margins; layout containers control spacing
between elements.

```css
*, ::after, ::before, ::backdrop, ::file-selector-button { margin: 0; padding: 0; }
```

## Media elements

Media elements (`img`, `video`, `canvas`, `svg`) retain browser-default display and
sizing in preflight. Containers explicitly control media constraints and aspect
ratios.

## Colour scheme

The root stylesheet declares `color-scheme: dark light`. Application `<meta name="color-scheme">`
tags must match this order to prevent rendering discrepancies before stylesheet evaluation.

```css
:root { color-scheme: dark light; }
```

`body` applies `--cn-surface` and `--cn-text` roles rather than raw color values.

## Hydration wrappers

Astro island wrappers declare `display: contents`, so an island generates no box and its
markup lays out as though written in place.

```css
astro-island { display: contents; }
```
