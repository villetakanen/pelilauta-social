Pelilauta's base styles are a modern reset, in the line of
[Andy Bell's](https://piccalil.li/blog/a-more-modern-css-reset/) and
[Tailwind Preflight](https://tailwindcss.com/docs/preflight) — both built on
[modern-normalize](https://github.com/sindresorhus/modern-normalize). Those pages
document what a modern reset does and why; this one covers what is specific to us.

```js
import '@design-system/styles/ds.css';
```

Import it once, anywhere in an application's shell. Preflight states only what no other
stylesheet does, so there is no order to get right.

## What we add

**Hydration wrappers are transparent.** Astro puts an `astro-island` element around a
hydrated component. It displays as `contents`, so a Svelte island inside a flex row
lays out as though its markup were written there.

```css
astro-island {
  display: contents;
}
```

**Dark is the no-preference default.** The document supports both schemes and names
dark first. An application's `<meta name="color-scheme">` states the same order, or it
has no effect — the CSS property wins.

```css
:root {
  color-scheme: dark light;
}
```

**The body carries the theme**, using the semantic background and text roles rather
than literal colours.

## What we leave to something else

| Not here | Where it lives |
| :--- | :--- |
| Prose margins, type sizes, leading, heading wrap | the type ramp |
| Constraining image width | the container holding the image |
| Scrollbar appearance | themed surfaces, not yet assigned |
| How a control looks once normalised | its component |

A reset that removed prose margins without stating the replacement would be a rule
waiting to be overridden, so the type ramp does both together.

## One thing worth knowing

List markers are removed only where you ask, following Bell rather than Tailwind:

```css
ol[role="list"], ul[role="list"], menu[role="list"] {
  list-style: none;
}
```

Safari drops a list's semantics from VoiceOver when `list-style` is removed, so a
navigation, menu or tray asks for both — the role keeps the semantics, the selector
removes the markers. Margins and padding are zeroed on every list regardless.
