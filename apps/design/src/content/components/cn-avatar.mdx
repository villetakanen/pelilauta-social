`CnAvatar` renders user and system profile avatars. It supports static server-side rendering
with pure CSS fallback layering: initials render beneath the profile image and display
automatically if image loading fails. Initial backdrops are computed deterministically from `nick`.

## When to use it

- Profile representations in feeds, discussion threads, headers, and member lists.
- Pass `nick` alongside `src` to supply initials, fallback backdrops, and accessible names.

Use the textual mark `.cn-nick` when displaying names as text. Architectural principles
and avatar list patterns are defined in [Identity Mark](/base/identity-mark).

## Variants and states

`CnAvatar` provides size options and three hierarchical fallback states.

### Fallback states

1. **Image:** Profile photograph clipped to a circular boundary.
2. **Initials fallback:** First two characters of `nick` over a derived backdrop.
3. **Anonymous glyph:** Generic avatar icon on `--cn-surface-2` when `nick` is omitted.

### Size variants

- **`small` (1.5 lines / 36px):** Sized for inline text pairings.
- **`medium` (2 lines / 48px, default):** Sized for feed items and section headings.
- **`large` (3 lines / 72px):** Sized for a view about the profile itself.

## Reference

### Props

| Prop | Type | Purpose |
| :--- | :--- | :--- |
| `src` | `string` | Profile image URL. Falls back to initials or anonymous glyph on failure. |
| `nick` | `string` | Profile nickname. Supplies initials, derived backdrop hue, and accessible name. |
| `size` | `'small' \| 'medium' \| 'large'` | Size variant. Defaults to `'medium'`. |
| `aria-hidden` | `boolean` | Hides the avatar from assistive technology. Defaults to `false`. |

### Tokens

`CnAvatar` publishes no custom properties. Its backdrop bands and foreground are private
values on the component, documented in [Identity Mark](/base/identity-mark), with
line-height multiples from [Units and grid](/tokens/units).

## Accessibility

`CnAvatar` announces `nick` as its accessible name.

Pass `aria-hidden="true"` when the avatar is paired with adjacent text that already names
the profile (such as an anchor containing both avatar and nickname). Avatars without a `nick`
are automatically hidden from assistive technology.

## Not shown here

**Client-side hydration transparency cleanup.** In hydrated client environments, the component
hides underlying initials upon verified image load to prevent bleed-through on transparent PNGs.
The static specimens here demonstrate pure CSS scriptless layering.
