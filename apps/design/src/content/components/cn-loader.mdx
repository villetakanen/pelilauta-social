`CnLoader` combines two visual signals: a spinning dual ring indicating active background
processing, and a centred static icon identifying the entity or domain being loaded.

## When to use it

- Render in unpopulated view containers while asynchronous data resolves.
- Pass the semantic noun corresponding to the subject being loaded (for example, `noun="fox"` for user feeds).
- Use `inline` mode when placing the loader on a text line or beside an action label.

In a button, render the command's `Icon` while the control is ready and an inline
`CnLoader` with the same noun while it processes. The glyph stays where it was and takes
the ring around it, so the control reads as the same button, busy.
[Links, Actions and Buttons](/base/links-actions-buttons) specifies the composition.

```svelte
<button type="button" disabled={sending}>
  {#if sending}
    <CnLoader inline noun="send" />
  {:else}
    <Icon noun="send" />
  {/if}
  <span>Send</span>
</button>
```

## Variants and states

`CnLoader` provides standalone and inline sizing variants, arbitrary icon noun configuration, and reduced-motion states.

### Sizing modes

- **Standalone (default):** Sized to 3 line units (`72px` / `--cn-loader-size`) and renders as a block container. Uses a large centred icon.
- **Inline (`inline={true}`):** Sized to 1 line unit (`24px` / `--cn-line`) and renders inline-block for integration on text lines without expanding the line box. Uses a small centred icon.

### Semantic noun assignment

Any approved catalogue noun can be passed to `noun`. Unknown nouns fall back to the standard missing glyph via `Icon`.

## Composition

A loader placed as a direct child of `<section>` or `<article>` is automatically centred
horizontally with 1 line of vertical margin via `styles/loader.css`.

<Composition themes caption="Standalone loader as direct child of a section">
  <LoaderSpecimens group="section" />
</Composition>

Within custom layout containers (such as inside a `CnCard`), the parent container must
explicitly position and centre the loader.

The ring and centred icon share a component-private colour, `--_loader-color`, declared
on `CnLoader.svelte`'s root rather than published on `:root`: `light-dark(--chroma-primary-60,
--chroma-surface-60)`, chroma step 60 of the primary family in Light and step 60 of the
surface family in Dark. The ring renders it at 0.72 opacity and the centred icon at 0.44
opacity.

## Accessibility

`CnLoader` implements an accessible live status region:
- Emits `role="status"` on the root container.
- Declares the accessible name via `aria-label={label}`.
- Hides the animated ring via `aria-hidden="true"`.

## Not shown here

**Reduced-motion pause.** Under `@media (prefers-reduced-motion: reduce)`, the ring animation
freezes while preserving the static dual ring and icon. This behaviour is asserted in
`apps/design/e2e/cn-loader.spec.ts`.
