Use the identity action to give the reader one destination for their own identity.

## When to use it

CnIdentityAction is a [Chrome Action](/base/chrome-actions) that takes one of two
modes: signing in, or the reader's own.

## Reference

### Props

| Prop | Type | Purpose |
| :--- | :--- | :--- |
| `href` | `string` | Required. The destination for the stated mode. |
| `label` | `string` | Required, and localised. The accessible name, and the visible label where the container declares labelled. |
| `signedIn` | `boolean` | The mode. Never derived from `nick` or `src`. |
| `nick` | `string` | The reader's nick, passed to the identity mark. Ignored where `signedIn` is false. |
| `src` | `string` | The reader's image, passed to the identity mark. Ignored where `signedIn` is false. |
| `disabled` | `boolean` | Removes the control from tab order and marks it `aria-disabled`. |
| `aria-current` | `string` | Marks the current destination. |

## Accessibility

The label is the accessible name in both modes. Signed in, the identity mark renders
`aria-hidden`.
