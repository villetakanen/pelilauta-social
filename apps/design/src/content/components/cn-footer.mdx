Use `CnFooter` to close a view with what is active on the platform now, where else the
community gathers, and what the platform is — three regions that balance across the
footer's own width rather than ranking against one another.

## When to use it

- Mount it once, at the end of the view's content, never inside application chrome.
- Fill `block-1`, `block-2` and `block-3` with independent content; leave any of them
  empty and it takes no track at all, rather than leaving a gap.

## Reference

### Props

`CnFooter` takes no props. It accepts content through three named slots.

| Slot | Purpose |
| :--- | :--- |
| `block-1` | The first region. |
| `block-2` | The second region. |
| `block-3` | The third region. |

## Accessibility

`CnFooter` renders a `<footer>` with an explicit `contentinfo` role, so it stays a
landmark wherever a layout places it — including inside `main`, where a bare
`<footer>` is none. Mount one per page; assistive technology lists every
`contentinfo` landmark it finds.
