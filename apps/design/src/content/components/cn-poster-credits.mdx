CnPosterCredits names the copyright holder of the artwork a [CnPoster](/components/cn-poster)
paints. The note is a string an application composes; the design system holds no licence
vocabulary.

## When to use it

Mount it in the last slot of the document footer on a page that carries a poster. The
note is not part of the poster: CnPoster is decorative and takes no focus stop, so a
readable, linkable credit cannot sit inside it.

## Example

<Composition themes caption="A linked note in Light and Dark">
  <CnPosterCredits
    note="Aamunkoin vartijat, Tapani Virtanen, CC BY-SA 4.0"
    href="https://creativecommons.org/licenses/by-sa/4.0/"
  />
</Composition>

```astro
<CnPosterCredits
  note="Aamunkoin vartijat, Tapani Virtanen, CC BY-SA 4.0"
  href="https://creativecommons.org/licenses/by-sa/4.0/"
/>
```

## Variants and states

`href` is the only variant. Without it the note is text; with it the note is a link, and
that link is the only focus stop this component adds. Its accessible name is the note.

<Composition themes caption="Unlinked and linked">
  <CnPosterCredits note="Aamunkoin vartijat, Tapani Virtanen, all rights reserved" />
  <CnPosterCredits
    note="Aamunkoin vartijat, Tapani Virtanen, CC BY-SA 4.0"
    href="https://creativecommons.org/licenses/by-sa/4.0/"
  />
</Composition>

## Composition

The footer is a CSS container, so the note measures the footer and wraps inside its
column. The note keeps the casing it is given, including inside a host that uppercases
its own footer text.

## Reference

### Props

| Prop | Type | Purpose |
| :--- | :--- | :--- |
| `note` | `string` | Required copyright text. An empty one emits nothing. |
| `href` | `string` | Links the note to the copyright holder or the licence. |
