A noun resolves to artwork before the response leaves, so an icon never moves when scripts
load. Monochrome artwork takes the
colour of the text around it. Branded artwork keeps the colours its source encodes.

[Iconography](/principles/iconography) explains which nouns exist and when to use an
icon at all.

## Example

<Icon noun="fox" />

```mdx
import Icon from '@design-system/components/Icon.svelte'

<Icon noun="fox" />
```

## Props

| Prop | Type | Purpose |
| :--- | :--- | :--- |
| `noun` | `string` | The artwork to resolve. Absent or empty renders the missing glyph. |
| `size` | `xsmall`, `small`, `medium`, `large`, `xlarge` | Defaults to `medium`. |
| `aria-label` | `string` | Overrides the noun as the accessible name. Defaults to the noun. |
| `decorative` | `boolean` | Removes the accessible name and the title tooltip. Defaults to `false`. |

## Sizes

Each size reads one token, so a context that re-declares the tokens resizes every icon
inside it.

## Colour

Monochrome artwork is `currentColor` and states no colour of its own. Set `color` on the
element around it — or let it inherit — and the icon follows, in both themes.

## Source tiers

A noun resolves through the open-source tier, then the managed tier, then the bundled
fallback, and finally the missing glyph.

## When to use it

- Any icon in `apps/pelilauta` or on this site.
- Artwork supplied from data, where the noun is a string you don't control.

Don't reach for an inline `<svg>` or a file under `/icons/`. Those URLs stay only for the
Cyan `cn-icon` consumers still fetching them, and `docs/MIGRATION.md` owns retiring those.

## Behaviour worth knowing

An unknown, empty, or absent noun renders the missing glyph at the requested size. v18
rendered a blank box for an unknown noun and its default artwork for an empty one, so a
surface that relied on either now shows a visible miss.

The managed tier is a submodule. With it absent, its nouns fall through to the missing
glyph and the build completes.

## Accessibility

The icon carries an `aria-label` — the noun, or the one you pass — and keeps the noun as
its SVG title, which is what a mouse tooltip shows. Passing a label changes the accessible
name only. A `decorative` icon exposes neither: nothing is announced, and no tooltip
appears, for an icon whose composition already carries the meaning or deliberately
withholds it.

An icon that is a control's only content doesn't name that control. The control owns its
own accessible name.
