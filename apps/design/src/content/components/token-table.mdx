import unitsSource from '@design-system/styles/units.css?raw'

Renders the custom properties a stylesheet declares, read from that stylesheet when the
page is built. Lexicon books use it so a published value cannot drift from the one that
ships.

## Example

<TokenTable
  source={unitsSource}
  names={['--cn-grid', '--cn-gap', '--cn-line']}
  caption="The spacing tokens"
/>

```mdx
import TokenTable from '@design-system/books/specimens/TokenTable.astro'
import unitsSource from '@design-system/styles/units.css?raw'

<TokenTable
  source={unitsSource}
  names={['--cn-grid', '--cn-gap', '--cn-line']}
  caption="The spacing tokens"
/>
```

A declaration's trailing inline comment becomes its last column. A comment on its own line
introduces what follows and is left alone.

## Props

| Prop | Type | Purpose |
| :--- | :--- | :--- |
| `source` | `string` | The stylesheet text, imported with `?raw`. Required. |
| `names` | `string[]` | Exact tokens to show. |
| `prefix` | `string` | Every token whose name starts with this. |
| `without` | `string` | Drops tokens whose name contains this, after the include filter. |
| `swatch` | `boolean` | Renders a colour chip per row, resolved through the live cascade. |
| `caption` | `string` | Names what the reader is looking at. |
| `noteLabel` | `string` | Heading for the trailing-comment column. Defaults to `Resolves to`. |

`names` and `prefix` are alternatives; rows come back in the stylesheet's order either
way, and a prefix with its `without` complement covers the file between them.

`swatch` resolves `var(--token)` in the reader's own mode, so a `light-dark()` role shows
the arm in force. Each chip carries `data-swatch="--token-name"` for browser checks.

## When to use it

- Any page that would otherwise state a token's value by hand.
- A lexicon book, where listing every token in a family is the page's job.

Do not use it to explain *which* token to reach for — that is a principles book's, such as
[Spatial System](/principles/spatial-system).

## Behaviour worth knowing

**A selection that matches nothing fails the build**, naming the filter that missed. After
a rename the alternatives are an empty table or every token in the file, and both publish
a page that is wrong without saying so.

It guarantees completeness, not correctness: it shows what the stylesheet declares, and
proves nothing about whether those values are right. Parity and derivation are asserted in
`packages/design-system/test/units.test.ts`.
