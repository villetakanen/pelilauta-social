import unitsSource from '@design-system/styles/units.css?raw'

`TokenTable` parses and renders CSS custom properties directly from raw stylesheet text
at build time. Trailing inline comments in CSS declarations populate the table's note
column.

## When to use it

- Render token declarations in lexicon books without manually transcribing values.
- Display verified token subsets with live cascade colour swatches.

Do not use `TokenTable` to explain design principles or token selection rationale;
refer to the appropriate principles book (such as [Spatial System](/principles/spatial-system)).

## Example

<TokenTable
  source={unitsSource}
  names={['--cn-grid', '--cn-gap', '--cn-line']}
  caption="The spacing tokens"
/>


## Variants and states

`TokenTable` supports filtering by explicit names or name prefixes, and optional colour swatch rendering.

### Token filtering

Pass `names` for an explicit token list, or `prefix` to include all tokens matching a leading substring. Use `without` to exclude matching substrings from a prefix query.

### Colour swatches

Setting `swatch={true}` renders an inline colour chip per row evaluated against the active theme (`light-dark()`). Each swatch element renders a `data-swatch="--token-name"` attribute.

## Reference

### Props

| Prop | Type | Purpose |
| :--- | :--- | :--- |
| `source` | `string` | Raw stylesheet string imported with `?raw`. Required. |
| `names` | `string[]` | Explicit token names to render. |
| `prefix` | `string` | Prefix filter matching custom property names. |
| `without` | `string` | Substring exclusion filter applied after prefix matching. |
| `swatch` | `boolean` | Renders a live colour swatch per row. Defaults to `false`. |
| `caption` | `string` | Accessible table caption text. |
| `noteLabel` | `string` | Header label for trailing comment column. Defaults to `"Resolves to"`. |

## Accessibility

`TokenTable` emits standard semantic HTML `<table>` elements with accessible `<caption>`
headers. Swatches are decorative elements hidden from assistive technology.

## Not shown here

**Build failure on unmatched filters.** If a configured `names` or `prefix` filter matches zero
declarations in `source`, the component raises a build error. This build-time validation is
verified by `packages/design-system/test/token-table.test.ts`.
