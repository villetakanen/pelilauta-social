Every colour token and its declared value. Which token to use is in the
[Colour System](/principles/color-system) book.

Each table is read from its stylesheet at build time. Swatches resolve in the theme you are
reading in, so a `light-dark()` role shows the arm currently in force.

## Semantic roles

Components read these. Each states both themes in one declaration.

## Elevation shadows

Declared in the same stylesheet. They are shadows, so they carry no swatch. They are grid
multiples and need `--cn-grid`, which `styles/tokens.css` supplies alongside them. See
[Units and grid](/tokens/units).

## Cyan 4 aliases are not here

`styles/compat/cyan-4.css` maps legacy names onto these roles until the surfaces still
running on Cyan are replaced. It is removed before `v21.0.0-rc.1` and nothing new reads it.
Read the stylesheet if you are migrating a surface. `docs/MIGRATION.md` owns the sweep.
