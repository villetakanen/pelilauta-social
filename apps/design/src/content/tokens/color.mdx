Declared color custom properties and values. Color selection and contrast rules are
defined in [Colour System](/principles/color-system). Swatches resolve dynamically
in the active color scheme.

## Semantic roles

Component-facing color tokens. Each role defines light and dark values in a single
`light-dark()` declaration.

## Elevation shadows

Elevation shadow tokens declared in `styles/color-theme.css`. Shadow geometry scales
with `--cn-grid` as defined in [Units and grid](/tokens/units).

<TokenTable source={themeSource} prefix="--cn-shadow" caption="Elevation shadows" />

## Reference palette

Primitive OKLCH color scales. UI components consume semantic roles rather than
referencing primitive palette tokens directly.

<TokenTable source={referenceSource} prefix="--cn-color-" swatch caption="Reference palette" />

## Cyan 4 aliases

`styles/compat/cyan-4.css` maps legacy names onto these roles until the surfaces still
running on Cyan are replaced. It is removed before `v21.0.0-rc.1` and nothing new reads it.
`docs/MIGRATION.md` owns the sweep.
