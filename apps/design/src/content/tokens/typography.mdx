## Font sizes

Font sizes scale by an Augmented Fourth multiplier (1:1.414) from the 17px reading baseline.
The `small` step sits outside the scale. The step set is closed: adding one is a spec change.
All values use `rem` and scale with the user's browser font size settings.

## Line heights

Line heights are multiples of `--cn-line` (24px). Each step takes the smallest multiple that
clears its text, except h1, which takes four rather than three.

## HTML element and utility mapping

HTML elements apply typography tokens by default without requiring classes:
- `body` applies the default text step.
- `h1` through `h4` apply their corresponding heading steps.

Matching utility classes are provided for all steps: `.text-body`, `.text-h1` through
`.text-h4`, `.text-title`, `.text-small`, `.text-caption`, and `.text-label`.

`.text-caption` and `.text-label` share the caption font size and line height:
- `.text-caption` applies uppercase transformation in Lato.
- `.text-label` preserves source casing and renders in Roboto Mono for identifiers, technical codes, and metadata.

## Container-responsive heading downscaling

Headings inside containers narrower than the small breakpoint (`38.75rem`) automatically
downscale by one step in the modular scale.

Heading levels retain their declared weight during downscaling, with the exception of
`h4`, which takes `--cn-font-weight-emphasis` (700) at reading size to preserve heading hierarchy.
`.text-title` does not downscale.
