# Notification Management System

Please note that in order to leverage the notification system, you simply need to understand how the notifications' storage is structured.

Which notifications have been read by the user, and which have not.

The component's own lifecycle manages its state. It is very easy and quick to implement.

## Notification List

The following table lists the various kinds of notifications:

| Type | Description |
| :--- | :--- |
| mention | When someone mentions the user |
| reply | When a reply is posted |
